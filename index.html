Why this works as a product

No model changes needed

Confidence is derived from source agreement and domain authority signals that already exist — this is a presentation layer, not a retraining effort.

Preserves answer speed

The badge renders with the answer. Sources load only on expand, so the fast, clean AI-answer experience stays intact.

Nudges, doesn't block

Low-confidence answers still show — just framed honestly, so users self-select into checking further rather than being blocked outright.
