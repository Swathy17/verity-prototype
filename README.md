## What this is
AI-powered search and assistant products are replacing ranked lists of sources with a single synthesized answer. That removes a signal users relied on for decades — seeing multiple sources and judging credibility themselves. Right now, users either trust the AI answer blindly or don't trust it at all, and neither is good for the product or the user.

**Verity** is an independent product concept that addresses this: a lightweight UI layer that shows a confidence badge on every AI-generated answer, with a one-tap breakdown of the sources behind it.

This repo hosts a working, interactive prototype of the idea — not a real search engine, but a functional demo of the interaction: a before/after comparison, and a live demo you can query yourself.

## How the prototype works
- **Compare view** — toggle between a standard AI answer and the same answer with the Verity confidence layer applied
- **Live demo** — try three preset queries (tuned to show High, Medium, and Low confidence states) or type your own
- All data shown is illustrative/simulated for demonstration purposes — this is a UX and product-thinking prototype, not a live AI system
